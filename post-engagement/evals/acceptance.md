# Acceptance

Walk every line. A checked template without an evidence-backed consumer adaptation is incomplete.

## Before deploy

- `node --import tsx evals/contract.mjs` passes against the adapted graph: two or more Cargo
  Signals models on `listenInfluencerEngagement`, each capped by `dailyLeadLimit`; one app with a
  relative `path`; no play, agent or workflow; no token in the app package.
- Every URL in `trackedProfiles` was opened and is the person it claims to be, and each handle has
  an `AUTHORS` entry.
- `ICP` was written from the workspace context, and `ownCompany` matches the company's own website
  and LinkedIn page.
- The live per-row price was read and said out loud, and `dailyLeadLimit` chosen against it.
- `npx tsc --noEmit && npx vite build` pass inside the app.

## First runs

Keep a screenshot of each view and the storage counts as evidence.

- **Sync.** Each model holds rows, all engaging with a tracked profile, no more per day than its cap.
- **Dataset.** `SELECT COUNT(*) FROM <DATASET>.<model>` answers for every model in `MODELS`.
- **Load.** The board shows no warning: counts reconciled, no unknown author.
- **Own company.** Nobody from the company is in the top ten people with the ICP filter on.
- **Score.** Reloading the board twice gives the same top ten.
- **Access.** Opening the app URL in a private window asks for a Cargo login and shows no data
  before it.
