# The drafts file

One file per ISO week, `cadence/content/<YYYY-Www>.md`, rewritten in place on a re-run.

```markdown
---
week: 2026-W41
author: Dana Ruiz
drafts: 3
---

# LinkedIn drafts, 2026-W41

## 1. Proof point: <five-word working title>

**Hook:** <the first line, the one that shows before "see more">

<the full post, first person, under 1,300 characters>

**Sources:** context/proof/<file>.md, context/client/<file>.md

## 2. Objection: <title>

...

## 3. This week: <title>

...

## Not drafted

<only when a kind could not be supported: which kind, and the file that would fill it>
```

## Rules for a draft

- **Three kinds, one each:** a proof point, an answer to an objection or misconception, and
  something learned this week.
- **The hook** is a number, a claim a buyer would argue with, or a sentence a customer said. Not a
  question to the void.
- **Every claim is in a source.** Every number, customer, quote, result or comparison appears in a
  file listed under **Sources**. A claim with no file is cut.
- **Customers** are named only when their `client/` file says `reference_permission: yes`;
  otherwise they are described ("a 240-person freight-audit company").
- **No repeats.** An angle or proof point drafted in the last eight weeks of `cadence/content/` is
  not drafted again.
- **The ending** is one question or one sentence the reader can act on. Never "thoughts?".
- At most two hashtags, no emoji bullets, and no competitor named.
