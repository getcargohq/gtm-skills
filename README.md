# Cargo GTM Skills

[![cargo-ai cli](https://img.shields.io/npm/v/@cargo-ai/cli?label=cargo-ai%20cli&color=black)](https://www.npmjs.com/package/@cargo-ai/cli)
[![skills.sh](https://img.shields.io/badge/skills.sh-46%20skills-black)](https://www.skills.sh)
[![License](https://img.shields.io/github/license/getcargohq/gtm-skills?color=black)](LICENSE)

46 agent skills for B2B go-to-market work, each with one routed job. Some run once, in a turn:
find the emails, score the list, brief me on this account. Others deploy a pipeline that keeps
doing that job after the session ends.

- **No account to read or install them.** A new Cargo account starts with **100 free credits,
  no card**, which covers a first run of any skill here.
- **Priced before it runs.** Every skill quotes its credits per call, CI checks them against the
  provider playbooks, and each one samples 10–20 rows before it asks to run the whole list.
- **Works in your agent.** Claude Code, Codex, Cursor, Windsurf, GitHub Copilot, and anything
  that supports the [skills.sh](https://skills.sh) standard.

```bash
npx skills add getcargohq/gtm-skills --all              # all 41
npx skills add getcargohq/gtm-skills/<skill-name>       # exactly one
cargo-ai project add cookbook/<skill-name>              # a pipeline, into your Cargo project
```

Pipelines install through `cargo-ai project` instead of `skills add`: each one carries resources
that have to land in your project's resources folder (the one its `cargo.json` names) while the
procedure goes to your skills folder, and only the CLI knows how to split them.

## Skills

Every skill page shows a line to say to your agent and an illustrative result. The tables below
are generated from each `SKILL.md`, so they never drift from what the skill actually does.

The pipelines are listed in stage order — Context, Fundamentals, Signals, Engagement, Operations,
CRM — and that order is the recommendation. Start anywhere: every pipeline installs and works on
its own. After one is set up, an agent suggests the earliest pipelines not set up yet.

The same 46 skills also install as one native plugin. Take this route when you want all of them
and two things `skills add` cannot give you:

- **Fewer prompts, same guardrails.** An approval hook ([`hooks/approve-cli.sh`](hooks/approve-cli.sh))
  auto-approves safe `cargo-ai` calls (reads, queries, runs and batches). Login, token minting,
  report egress and any `remove`/`delete` still ask. It can only allow, never override a deny rule.
- **The CLI the skills were written against.** In Claude Code, a session hook installs the CLI
  version that [`cli-version`](cli-version) pins and keeps the session titled.

**Claude Code** (≥ v2.1.154):

```
/plugin marketplace add getcargohq/gtm-skills
/plugin install cargo@gtm
```

**Codex:**

```bash
codex plugin marketplace add getcargohq/gtm-skills
# then install "Cargo GTM" from the Plugins menu
```

**Cursor:** open **Customize** in the sidebar, add the `getcargohq/gtm-skills` marketplace, then
install the **Cargo GTM** plugin.

**Pick one channel.** The plugin and `skills add` both register the skills, so using both gives you
duplicates (plugin copies are namespaced `cargo:<skill>`).

## Want all of it?

These are slices of the full [Cargo skills pack](https://github.com/getcargohq/cargo-skills): 17
skills covering the whole CLI, with recipes, provider playbooks and cost discipline built in. If you
install the pack you don't need these, because each one here defers to `cargo-gtm` when it is
present.

```bash
npx skills add getcargohq/cargo-skills
```
